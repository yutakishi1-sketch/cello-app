How to install

チェロのアプリを
スマホに入れる

「ドヴォルザークへの道」はアプリストアを使いません。ブラウザで開いて、ホーム画面に置くだけ（無料・1分）。下の画面が動画のように手順を見せます。

STEP 1 / 6

    アプリの住所

    https://yutakishi1-sketch.github.io/cello-app/

    パソコンでこのページを見ているときは、スマホのカメラでこの四角を読むと、アプリのページが開きます。

    うまくいかないとき

    こうなったらこうする
    「ホーム画面に追加」が見つからない共有の一覧を上へ送ると下のほうにあります。それでも無ければ「もっと見る」（「その他」）を押します。
    右下に「⋯」が無い（iPhone）古い型の画面です。下の真ん中の共有ボタン（四角から上向きの矢印）を押し、手順4から続けます。
    LINE やメールの中で開いた右上か右下のメニューから「ブラウザで開く」（iPhone は「Safariで開く」）を選び、手順1からやり直します。
    アイコンを押すと、上に住所の帯が出るiPhone で「Webアプリとして開く」がオフでした。アイコンを長押しして削除し、オンのまま入れ直します。

    知っておくと安心

    • iPhone は、ホーム画面のアイコンから開いてください。Safari で開いたときとは、練習の記録が別々になります。
    • 新しい版は、開き直すと自動で入ります。入れ直しは要りません。
    • iPhone でアイコンを削除すると、記録も一緒に消えます。入れ直すときは気をつけてください。

    画面の形は iOS 26・Android の Chrome に合わせた見本です。機種や設定によって、ボタンの位置や言葉が少し違うことがあります。
